
# 🎮 Retro Game

## 📌 Sobre o Projeto

O Retro Game é um site desenvolvido para cadastrar e gerenciar jogos de videogame.

O projeto foi criado utilizando HTML, CSS e JavaScript, permitindo que o usuário adicione jogos ao catálogo de maneira simples e organizada.

O site possui um visual inspirado no universo gamer, com cores escuras e detalhes em roxo.

## 🚀 Funcionalidades

- ✅ Cadastrar novos jogos
- ✅ Adicionar nome do jogo
- ✅ Selecionar a plataforma
- ✅ Informar o gênero do jogo
- ✅ Adicionar imagem pela URL
- ✅ Definir o preço do jogo
- ✅ Visualizar os jogos em cards
- ✅ Pesquisar jogos pelo nome
- ✅ Excluir jogos cadastrados
- ✅ Salvar jogos no LocalStorage
- ✅ Layout responsivo para celulares e computadores

## 🛠️ Tecnologias Utilizadas

- HTML5 — Estrutura do site
- CSS3 — Estilização e responsividade
- JavaScript — Funcionalidades e interatividade
- LocalStorage — Armazenamento dos jogos no navegador

## 💻 Como Executar

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Instale a extensão Live Server, caso ainda não tenha.
4. Clique com o botão direito no arquivo index.html.
5. Selecione "Open with Live Server".
6. O site será aberto no navegador.

## 🎮 Como Utilizar

1. Acesse o site Retro Game.
2. Clique no botão "+ Cadastrar Jogo".
3. Preencha os campos solicitados:
   - Nome do jogo
   - Plataforma
   - Gênero
   - URL da imagem
   - Preço
4. Clique em "Salvar Jogo".
5. O jogo aparecerá automaticamente no catálogo.
6. Utilize a barra de pesquisa para encontrar jogos.
7. Clique em "Excluir Jogo" para remover um cadastro.

## 💾 Armazenamento

Os jogos cadastrados são armazenados no LocalStorage do navegador.

Isso permite que os dados permaneçam salvos mesmo após atualizar ou fechar a página.

Os dados são locais e não são compartilhados entre dispositivos.
